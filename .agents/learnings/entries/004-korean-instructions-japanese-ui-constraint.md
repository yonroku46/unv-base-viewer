### Problem / Context (문제 및 배경)
개발자가 한국어로 편하게 작업을 지시(예: "마이페이지 만들어줘", "검색 결과 화면 구현해줘")할 때, AI 에이전트가 무심코 컴포넌트의 버튼 라벨이나 헤더 텍스트를 한국어로 생성하거나 직역투 어색한 표현을 넣는 실수가 발생할 수 있음.

### Root Cause (근본 원인)
사용자의 프롬프트 언어(한국어)를 그대로 UI 텍스트로 반영해버리는 에이전트의 기본 동작 성향.

### Rule & Solution (해결책 및 향후 규칙)
1. **내부 커뮤니케이션 & 문서**: 한국어로 유지 (개발자의 빠른 확인 및 피드백 가능).
2. **코드 생성 시 필수 전환**:
   - 화면에 노출되는 모든 라벨(`ホーム`, `お知らせ`, `ログイン`, `保存する`, `キャンセル` 등), 플레이스홀더, 알림 문구는 반드시 자연스러운 **일본어(丁寧語/敬体)**로 작성한다.
   - `generatePageMetadata()`의 타이틀과 설명도 일본어로 작성한다.
   - 날짜/시간 포맷은 `@/common/lib/Dayjs`를 사용하여 일본 로케일(`ja`) 및 타임존(`Asia/Tokyo`) 기준으로 표시한다.
