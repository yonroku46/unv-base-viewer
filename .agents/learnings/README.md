# AI Agent Learnings Knowledge Base

이 디렉토리는 AI 에이전트가 본 프로젝트에서 작업하면서 겪은 기술적 이슈, 해결 방법, 컨벤션 위반 경험, 주의사항을 축적하는 영구 지식 베이스입니다.
과거의 실수를 반복하지 않고 프로젝트가 진행될수록 코드 품질과 작업 정확도가 향상되도록 관리됩니다.

## 1. 에이전트 행동 지침 (Agent Protocol)

모든 AI 에이전트는 작업을 시작할 때와 완료할 때 아래 절차를 반드시 따라야 합니다:

1. **작업 시작 전 (Check Learnings)**:
   - 본인이 수정하거나 추가하려는 영역의 `scope`와 관련된 `entries/*.md` 파일들을 먼저 확인합니다.
   - 과거에 동일하거나 유사한 작업에서 발생했던 실수나 주의사항을 인지한 상태로 설계를 진행합니다.
2. **작업 완료 후 (Record Learnings)**:
   - 사용자로부터 지적/피드백을 받았거나, 빌드/린트/타입체크 과정에서 예기치 않은 오류를 해결한 경우 반드시 새로운 러닝 파일(`entries/<id>.md`)을 생성하거나 기존 러닝을 갱신합니다.
   - 단발성의 사소한 오타나 로컬 환경 이슈가 아닌, **재발 가능성이 있는 기술적 제약, 아키텍처 규칙, 라이브러리 호환성 문제**를 기록합니다.

## 2. 러닝 엔트리 파일 규격 (`entries/<id>.md`)

각 파일은 다음과 같은 YAML frontmatter와 본문 형식을 갖춥니다:

```markdown
---
id: 001-sample-learning-title
title: 간결하고 명확한 학습 제목
date: 2026-10-19
scope: [nextjs, ssr, styling, api, build]
status: active
---

### Problem / Context (문제 및 배경)
어떤 작업을 수행하던 중 어떤 문제가 발생했는지 설명합니다.

### Root Cause (근본 원인)
문제의 원인이 무엇이었는지 기술적/구조적 배경을 적습니다.

### Rule & Solution (해결책 및 향후 규칙)
앞으로 동일한 실수를 방지하기 위해 에이전트가 반드시 따라야 할 규칙을 명시합니다.
```
